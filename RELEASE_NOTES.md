## FileNavigation v0.1.11

- Results now use a collapsible multi-level tree relative to the selected root. Folders are listed first by name in the default sort, and folder sizes total all descendant files in the result tree.
- Selecting a folder with an empty file-name keyword now browses all visible entries under that folder, up to the configured result limit.
